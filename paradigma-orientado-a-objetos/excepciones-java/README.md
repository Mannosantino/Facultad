# Manejo de excepciones en Java

Trabajo práctico académico enfocado en el tratamiento de errores y excepciones con Java.

## Objetivo

Practicar el uso de excepciones para detectar, comunicar y controlar situaciones inesperadas durante la ejecución de una aplicación.

## Tecnologías

- Java
- Programación orientada a objetos
- Manejo de excepciones

## Contexto académico

Ejercicio realizado en UADE para la materia Paradigma Orientado a Objetos.

> Este repositorio forma parte de las prácticas de la materia y documenta el progreso de aprendizaje.
