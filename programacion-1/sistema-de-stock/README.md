# Sistema de gestión de stock

Aplicación académica de consola para gestionar productos, categorías, movimientos de inventario y usuarios.

## Funcionalidades

- Registro e inicio de sesión de usuarios
- Generación y procesamiento de archivos CSV
- Consulta de productos por categoría
- Detección de productos con bajo stock
- Identificación de próximos vencimientos
- Estadísticas y rankings de inventario
- Gestión de usuarios
- Registro de actividad en una bitácora

## Archivos generados

- `categorias.csv`
- `productos.csv`
- `movimientos.csv`
- `porcentajeCategoria.csv`
- `porcentajeStockMayor20.csv`
- `bajoStock.csv`
- `proximoVencimiento.csv`
- `resumen_estadistico.csv`
- `bitacora.log`

## Uso general

Al iniciar la aplicación se puede registrar un usuario o iniciar sesión. Desde el menú principal es posible generar datos de entrada, procesar el inventario, consultar reportes y administrar usuarios.

Las opciones numéricas validan la entrada y utilizan valores predeterminados cuando corresponde.

## Contexto académico

Proyecto realizado en UADE para aplicar programación estructurada, validación de datos, procesamiento de archivos y diseño de menús interactivos.
