# Portfolio médico

Portfolio web académico con una interfaz profesional orientada al ámbito de la salud.

## Descripción

Sitio de una sola página desarrollado como trabajo universitario. Organiza información profesional y académica mediante una navegación clara, secciones temáticas y una presentación visual adaptable a distintos tamaños de pantalla.

## Características

- Navegación fija entre secciones
- Diseño responsive
- Jerarquía visual orientada a lectura profesional
- Componentes y tarjetas informativas
- Animaciones y estados interactivos
- Paleta visual inspirada en el ámbito médico

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Cómo ejecutarlo

No requiere instalación:

1. Clonar o descargar el repositorio.
2. Abrir `index.html` en un navegador.

## Contexto académico

Proyecto realizado en UADE para practicar diseño y desarrollo web. El contenido se utiliza con fines educativos.
